# Pharma analyst report template

Use this outline selectively. Omit empty sections and lead with what matters to the user's decision. Unless the user asks for a brief note, write a substantial report: combine structured tables with interpretive prose, cover material counterevidence, and cite sources throughout.

## Header

- Subject:
- Report type:
- Report date:
- Data cutoff (`As of`):
- Geography/currency:
- Scope and key assumptions:

## Executive view

State the conclusion in 3-6 bullets:

- Core thesis
- Strongest evidence
- Largest uncertainty
- Most important catalyst
- Valuation or strategic implication, if in scope

Include a compact dashboard when useful:

| Metric | Current view | Evidence grade | Why it matters |
|---|---|---|---|

Follow the dashboard with a short thesis paragraph explaining how the key evidence connects to the conclusion.

## 7. Regulatory, CMC, and IP

Present regulator-confirmed facts first. Separate CMC risks from biological risks. Label patent/FTO discussion as non-legal research intelligence.
